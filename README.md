# Computational Physics and Astrophysics

A collection of Jupyter notebooks exploring numerical models in computational physics and astrophysics.

## Projects

| Folder | Notebook | Contents |
| --- | --- | --- |
| `Hydrogen_Ionization/` | `hydrogen_ionization_equilibrium.ipynb` | Hydrogen species populations (H, H+, H−, electrons), equilibrium calculations, density dependence, and time-dependent rate equations. |
| `Computational_Dynamics/` | `stellar_wind_dynamics.ipynb` | Numerical integration of stellar wind trajectories, dust formation thresholds, radiative acceleration, and comparisons with analytical velocity estimates. |
| `Radiation_Matter/` | `radiation_matter_interactions.ipynb` | A radiation–matter numerical calculation using atomic transition parameters. |
| `Atomic_Excitation/` | `sodium_excitation_cross_sections.ipynb` | Sodium excitation cross-section calculations and plots. |
